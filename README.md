# Rollers

A small Unity personal project I'm working on while self-learning Unity. A top down shooter where you control a ball and shoot down enemies as you try to survive as long as possible.

Move: WASD
Shoot: Arrow keys

Features:
* Score, lives, and a timer!
* Difficulty scaling based on the timer!
* Sounds and visual effects!
* Title and game over screen!
* A rolling ball!
